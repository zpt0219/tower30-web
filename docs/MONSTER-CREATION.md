# 新怪兽制作流程

工作台的 **＋ 新增怪兽** 现在打开完整制作弹窗，不再立即复制一个临时角色。

1. 填写名字，最多40字。
2. 上传自己的PNG。右侧立即显示图片与尺寸；透明背景适合战场。
3. 选择属性与技能模板。右侧列出模板的生命、攻击/法术、防御/魔抗、自动技能和大招；实际复制基础属性、每级成长、定位、技能、被动、品阶、升级需求等配置。模板可以是原有怪兽，也可以是已有的自定义怪兽。
4. 点击 **创建怪兽**，自动定位到新角色的编辑页。之后可以继续修改属性、介绍和技能；在 **测试设置 → 我方伙伴** 选中它，再点击 Play。也可以在关卡页把它设为敌人。

图片和名字校验通过后才允许创建。取消、关闭或按 Escape 都不新增角色，也不会修改已有草稿。模板和PNG各自独立：用龙模板可以制作普通尺寸的角色图，属性不会被图片尺寸改变。

## PNG规格

- 每张不超过约220KB，宽高在1—2048像素之间。不是PNG、文件损坏或超出限制都会在弹窗内提示；原草稿保留。
- **单张角色图**：按原比例显示完整图片，战场上作为静态角色外观，不伪造行走帧。
- **3列×4行行走图**：支持48×64、96×128、192×256px，分别为16、32、64px方形帧，使用与现有怪兽相同的方向和步行取帧方式。
- 默认自动识别。若普通立绘恰好与行走图尺寸相同，可在“图片用法”明确选择单张角色图。
- 图片只负责外观；生命、碰撞、射程、移动和技能由模板及玩法核心决定。创建后切换内置贴图会自动匹配其切片规格。

## 保存、试玩与交接

草稿自动保存到浏览器，包含原始PNG。刷新后角色、模板结果和图片都保留。Play使用配置与图片的独立快照；战中刷新恢复同一次测试并暂停，正式30层进度和资源不受调试角色影响。

跨设备请使用 **导出工程 (ZIP)**，包内含工程JSON、原始配表、图鉴说明及PNG。重新导入会校验PNG，并恢复可编辑角色和外观。工程总JSON仍有2MB上限；超过时弹窗会显示错误并保留输入，不提交半成品。可先缩小PNG再试。

修改角色ID会同步自己的PNG及共享贴图引用。删除怪兽时，如其它怪兽还在使用它的PNG，会保留该图片；最后一个使用者删除后才清理。关卡仍在使用的角色，需要先替换对应敌组。

独立“测试记录”JSON仍只记录玩法与命令，不包含PNG；带图片交换作品请使用工程ZIP。本次实现和验收范围是网页端，没有新增Godot原生自定义贴图加载或APK导出。

夜翼蝠模板的汲血移速加成已改为可复制的可选配置，新ID和改名后都可保留；旧20Hz记录仍遵循原历史规则。原始40物种、30关和正常资源配置未修改。
