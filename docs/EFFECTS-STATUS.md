# v0.7 · 技能效果参数

已将完整30层与M4首版提交为`19bd885`（v0.6稳定基线）。本次继续扩展网页调参，正式战斗、独立Play和A/B批测共用同一套参数读取与玩法实现。

## 编辑入口

工作台 → **技能 · 73**。

- **毒刺 / 熔弹**：新增持续伤害属性比例。毒刺默认1/6，熔弹默认1/8；每秒伤害取整后最低1，填0不附加持续伤害，直接伤害不变。
- **9个数值护盾技能**：嫩叶守护、森息、叶幕治疗、森林庇护、净化帷幕、钳盾、潮壳阵、银壁、银光庇护。每个技能的Lv.1/2/3分别设置护盾倍率；某级留空只沿用该级原规则，不继承其它级的改值。填0不生成新盾，已有更强护盾不会被清除。
- 技能列表顶部的**效果与被动**：17项共用参数。影响本份配置中双方全部使用者，按状态、被动、护盾、装备分组，并显示核心当前生效值。

共用参数包括：中毒时治疗保留、急速增益及移动倍率、减速移动倍率、虚弱输出保留、破甲防御保留、持续恢复、反伤比例/冷却、蓄势普攻、净化附盾、护体减伤、物理/法术庇护，以及溢出转盾比例/上限、应急和援护护盾。

例如减疗输入20表示保留20%治疗；100表示治疗不再被抑制。反伤输入50表示以实际生命损失的50%作原始反伤，再按原规则结算防御。急速仍与属性急速相加并受既有上限限制；护体和庇护仍受原最终减伤上限限制。范围、前后摇、持续时间、主伤害/治疗倍率和固定值继续使用原有编辑器。

所有新字段都可留空继承，提供单项或整组恢复默认；数值范围、未知字段和不适用的技能参数都会校验。错误草稿仍可修复，不能进入Play或有效批测。原JSON不增加字段、不改字节；草稿和工程导出保存覆盖项。配表中的说明文字不自动改写，实际效果数值以参数页和核心记录为准。

## 规则与记录

`Rules.Effects`为可选的共用覆盖；`Rules.Actions.<id>.DotRatio`与`ShieldRatios`为可选的逐技能覆盖。`ShieldRatios`的空级用`null`表示继承；编辑器会移除全部为空的数组或空效果对象，恢复原配置指纹。默认毒伤继续使用原来的除法和取整顺序，避免浮点乘法在整数边界改变伤害。

参数在创建引擎时冻结。正在进行的Play和批测保留开始时的值，编辑草稿不改写在途战斗、命令记录或历史报告。投射物仍保存出手时的动作规则与属性，后续护盾、反击或毒伤使用同一核心结算。

新独立测试记录与批测记录使用`tower30-ts-workbench-v5`。保留v4恢复，导出后升级为v5；v1/v2/v3仍明确拒绝。用v0.6真实生成的中途记录验证完整快照、随机状态、位置、生命、能量和动作状态精确一致，再验证继续保存/恢复。此记录为专门生成的测试产物，不是玩家存档。

正式存档保持`tower30-ts-m3-v1`，原始配置指纹仍为`fnv1a-1713cdf4`。默认参数不写入新字段，不影响原正常30层资源路径。旧版本代码无法读取含新覆盖项的v5记录；回退时使用另存的旧格式记录。
