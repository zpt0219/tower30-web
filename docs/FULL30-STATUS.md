# v0.5 · 30层正常资源闭环

v0.4已提交为 `07ce207`，可回退到前20层版本。v0.5开放正式1—30层、30层Boss与完成页；40物种全部可在工作台完整Play。已完成M3的战斗与资源闭环、管理页及战报明细。M4的批量模拟、统计和配置方案对比尚未实现。

## 现行规则

40物种配置、装备和Boss覆盖实际使用的70个动作、32种非空被动均已接入同一个纯TS核心。原动作目录仍有73个ID；没有被现行配置引用的 `guard / ward / rally` 三个旧动作保留但不执行，完整模式会明确阻止，数值模式会明确停用，未伪装成已迁移技能。

补齐：顺风/狂袭急速、地震/岩牢、聚拢、晶刺破盾、棱镜优先攻击护盾、持续伤害/毒雾/治疗抑制、净化与群体庇护、反伤、蓄势反击、受控追加吸血、低血增伤及其投射物生命比例快照。保留固定tick、动作/弹道、控制保护、1000能量及既有经济规则。

战场新增敌方大招吟唱提示与剩余秒数，便于手动打断。战报能查看实际输出/治疗/吸收及三类回能、大招、暴击、闪避、受打断和硬直明细。30层确认战果后由核心真实进度显示完成页，可回看战报和关卡、继续整备或进入工作台；不会发放免费恢复或重复奖励。

工作台仍编辑42角色、30关、时间轴、倍率/固定值、射程/范围/持续时间，Play保存冻结配置。持续伤害的基础比例、增益强度等未另增逐项编辑器，仍按现行技能定义执行，可通过属性与既有参数调试；更多效果参数编辑属于后续工具迭代。
