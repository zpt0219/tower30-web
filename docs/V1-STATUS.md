# 首版试玩交付记录

日期：2026-10-31。版本：0.1.0，核心逻辑版本 `tower30-ts-m1-v1`。

本版完成 **M0 与 M1 的前两层可玩切片**，接入部分M2整备功能。**不是完整30层游戏，M2/M3/M4尚未完成。**

## 可实际操作的内容

- Vite + vanilla TypeScript，严格类型检查。DOM/CSS整备页，Canvas 2D战场；`src/core/`额外使用无DOM、无Node类型的编译检查。
- 原始JSON不变，运行时校验30层、40物种、42个战斗角色、73个动作与装备/经济引用。图鉴保留全部40物种，楼层资料可浏览。
- 初始两人、240金币、3草药、1复活羽及两把初始武器。没有赠送调试资源，没有跳层或预设胜负。
- 第1层“史莱姆初见”、第2层“蘑菇精初见”：固定0.05秒tick，独立战场，圆形碰撞、网格寻路与目标排序，入场、动作前后摇、真实投射物、伤害/治疗、减速、受击硬直、1000能量手动大招。
- 六项当前技能：迅击、稳击、治疗、新芽复苏、水弹、涌潮。5首发、每方最多10名存活在场、初始1张补人票、每8秒恢复1张、最多存3张；核心支持300秒超时和失败/撤回。
- 胜利收集：怪兽一级一阶、半血加入；掉落和收集不可重复。战报同屏列实际伤害、有效治疗、护盾吸收。确认战果后推进楼层并领取金币。
- 基础物品商店、有限库存持久化、合法买卖、穿戴占用限制和换装对比。初始武器不能出售；只开放已实现的装备。未迁移技能的装备有明确锁定。
- 草药/复活道具、付费旅馆、药水升级/找零/退还、魂魄升至二阶。升级和过层不免费治疗；存活成员跨战保留能量；无按时间回能。
- IndexedDB事务保存当前档和备份；导入/导出JSON；战中可保存。存档保存初始种子、引擎版本、配表指纹、tick和已接受命令；恢复时通过同一核心重放，重建全部动作、投射物和奖励状态。不是直接信任导入的生命/金币。
- 主档损坏回退备份；双档损坏时隔离原件、提供导出，并阻止静默覆盖。暂停会触发保存；状态文字在写入完成后才显示已保存。
- 暂停、单tick、1/2/4倍速和最近事件检查。后台自动暂停，返回后手动继续，不追算后台经过的时间。这些属于M1验证工具，不代表M4编辑器已经完成。

## 检查

交付检查使用Node 22.22.1，npm锁定依赖。`npm ci`已执行成功，`npm audit`为0项。项目提供 `.npmrc` 绕过本机npm 9/10在Vitest可选浏览器peer依赖图上的Arborist崩溃；浏览器测试独立使用Playwright。

实际通过：18项核心测试、10项浏览器流程，以及桌面/横屏两次生产构建连续两层试玩。严格检查和构建通过。具体结果见同目录NAS产物中的日志、`e2e-results.json`与`production-check.json`：

- `npm run typecheck`：应用及无宿主API核心严格检查。
- `npm run test -- --run`：核心、数据、确定性、存档、经济及C#迁移对照。
- `npm run build`：产出独立静态 `dist/`。Zod依赖有两条注释注解移除提示，不影响构建；无应用编译错误。
- `npm run test:e2e`：1280×720桌面和1000×450（20:9）横屏各5项浏览器流程。
- `node scripts/verify-static.mjs http://127.0.0.1:4173/`：对生产构建以独立静态HTTP服务连续打完前两层，检查370金币、实际导出存档、无页面异常及无外部请求。

浏览器流程覆盖：购买数量/总价、取消不扣钱、预览不换装、确认换装、40物种检索、返回保留筛选、触控滑动不误购、两层正常资源胜利、战报、刷新恢复、后台暂停和单步、损坏存档回退与隔离。截图已实际查看并修正桌面挑战按钮和横屏装备页布局。

手机横屏为 **Chromium触控模拟**，未声称真机验收。后台暂停用可见性事件模拟检查，尚未做手机系统锁屏/浏览器冻结后的硬件级验证。
