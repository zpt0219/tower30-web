## 本次修复

- 怪兽修改 ID 时同步关卡敌组、测试阵容和策略顺序。拒绝保留的对象属性名称；新增、改名后的角色没有原始基线时明确提示。
- 恢复角色基线通过物种 ID 查找，不再使用删改后可能错位的数组下标。
- 属性卡片保留基础/成长同屏布局，并恢复稳定输入框 ID，保证已有批量对比和策略流程仍可操作。
- 统一原始配表 Sprite 名称与本仓库 ID.png 文件的映射。Canvas 和战场头像根据当前运行配置加载；新增或改名的怪兽可以使用已有素材；切换内置贴图时自动匹配对应的 16/32px 切片，避免大型模板换普通外观后裁错。返回正式流程会重新使用正式配置，避免草稿贴图修改影响正式战场。
- ZIP 导出冻结当前工程，包含配表、工程 JSON、怪兽说明和实际 PNG；选择其它怪兽外观时导出正确字节。素材读取失败会报告错误，不再下载缺图却提示成功的包。ZIP 导入校验 CRC、目录与数据边界、重复文件及路径。
- 恢复普通工作台页的 Godot 工程导出入口。修正短屏样式相互覆盖造成的页签遮挡、过窄工具栏，以及 32px 的关键触控按钮；桌面与手机横屏工具栏按钮均至少 48px。新增按钮有明确的可访问名称，并修复悬停时文字与背景对比度不足的问题。

正式基线仍为 30 层、10/20/30 Boss、40 物种及两名人类。可变角色库属于工作台草稿；本次没有改动原始配表和正式起始资源。
