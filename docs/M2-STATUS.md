# v0.3 · M2 前10层

正式流程现已开放第1—10层。42个角色和30关仍可在工作台独立配置、Play；第11—30层的正式流程尚未开放。M0/M1已完成，M2已通过下述资源与浏览器验证；M3完整30层和M4批量模拟仍待推进。

## 本次实现

- 共24个动作：原有 `swift / steady / heal / renew / water / tide`，新增 `leafward / forest_rest / aegis / shellwall / bait / taunt / huntbite / pounce / gust / interrupt / firebolt / fire_rain / ram / rupture / boss_stomp / breakstrike / wardheal / flame`。
- 前10层相关被动：减速延长、低血治疗、盾上治疗、护盾人数、常驻减伤、充能效率、低血追击、破甲追加、灼烧追加的判定。火雨忠实沿用原核心的定时领域伤害，不另加原规则没有的Dot状态；后续毒伤技能仍待迁移。
- 护盾、减伤时限、嘲讽与优先目标、追击吸血、控制免疫及韧性缩短、眩晕打断、破甲、净化、火雨领域和周期伤害。每tick的前后两次身体分离均保留。
- 阶段0/1全部装备可用，包括裂甲/守护/叶幕武器、赤焰之书、充能饰品、溢出治疗转盾、非致死救急盾、补人援护光环。现代充能饰品使用属性加成，不再重复叠旧版额外回能。
- 工作台“技能 · 73”可编辑前后摇、弹速/寿命、可打断性、三级倍率/固定值，以及可选 `Range / Radius / Duration` 覆盖。自动技能冷却仍在角色页。倍率用于物理/法术伤害及治疗；buff自身系数沿用原规则。范围覆盖用于涌潮、碎甲冲、火雨，持续覆盖用于该技能已有的状态效果；无该效果的动作不凭空获得新效果。
- 火雨区域、护盾、眩晕/嘲讽/减伤/破甲在Canvas显示。入场和受控时的大招按钮禁用。

原始两份data JSON字节未改，SHA-256与 `data/SOURCES.json` 完全一致。构建、浏览器和常规测试无需兄弟Godot工程。
