# 网页配置工作台 v0.2

本次按用户的新优先级，提前实现M4中的“网页编辑配置 → 点击Play测试”子集。正式30层资源闭环和全部技能迁移仍按M2/M3继续，不把调参测试计入通关。

## 操作

1. 运行 `npm run dev -- --host 0.0.0.0`，打开终端地址，点击首页“编辑属性与关卡 ▶ Play”或侧栏“工作台”。
2. 在“角色 · 42”选择人类或怪兽，直接修改输入框；“基础属性”和“每级成长”分别编辑。右侧最终属性由同一TS核心计算，包含测试等级及已选初始装备。
3. 在“关卡 · 30”选择任一关，调整敌人组合及参数；选中的关卡就是Play目标，不要求先通关。也可在“测试设置”调整阵容、等级、起始生命/能量和固定种子。
4. 点击绿色“▶ Play 第N关”，立即进入真实实时战斗。可暂停、倍速、单tick、手动大招、补人；“返回编辑”停止测试并回到刚才的面板，“重新Play”用本次冻结配置重开。

浏览器草稿自动保存，也可点击“保存草稿”。“导出工程”包含完整原始配表和测试设置；“导出配表”只下载配置JSON；“导入”支持两者。无效输入会标出并禁用Play，保存的无效草稿刷新后仍可继续修复。导入先完整校验，失败不替换现有草稿。

纯静态网页将草稿存到IndexedDB，或通过下载导出；不会直接覆盖磁盘上的 `data/tower/thirty-floor-trial.json`。跨设备使用请导出再导入。原始两份JSON字节和hash保持不变。

## 可编辑内容

| 模块 | 字段 |
| --- | --- |
| 42个角色 | 生命、攻击、防御、法术、魔抗、暴击、穿透、急速、闪避、吸血、韧性、充能；基础和每级成长分别编辑 |
| 行动与空间 | 定位、普攻物理/法术类型、弹道、攻击间隔、技能冷却、前摇比例、移动速度、射程、碰撞半径 |
| 技能选择 | 自动技能及大招的现有动作ID；界面区分已实现和待迁移 |
| 30个关卡 | 名称、主题、提示、背景、金币、装备奖励 |
| 每个敌组 | 增加/删除编组、物种、数量、等级、阶数、生命/攻击与法术/防御倍率、战斗经验、魂魄、三种经验药水奖励；可清除专用技能覆盖 |
| 测试设置 | 任意关卡、1—10名我方角色、等级、怪兽阶数、生命比例、起始能量、种子、初始武器开关、技能测试模式 |

Boss标记固定保留在10/20/30关；每关最多16名敌人，5首发，其余按原补人票机制入场，每方最多10名存活在场。过大的碰撞半径若无法部署，核心会拒绝开战并还原战前状态。

百分比按0—100填写；叠加后保留原属性硬上限：暴击75%、急速100%、闪避40%、吸血60%、韧性60%、充能效率100%。人类装备初始武器时会有装备加成，武器可能覆盖自动技能。普攻物理类型使用攻击值，法术类型使用法术值。

为了统一调整人类和怪兽，编辑碰撞半径、射程和移速时，草稿会新增 `Rules.Combatants.<ID>.Radius / AttackRange / MoveSpeed` 覆盖项；未设置时沿用原物种或人类默认值。

## Play模式的范围

“数值与已实现技能”模式允许独立测试全部30关。当前可完整执行的技能为迅击、稳击、治疗、新芽复苏、水弹、涌潮；未迁移技能和三阶被动会在工作台预览及战场明确列出并停用，不替换成其它技能。基础攻击、移动碰撞、属性与暴击/闪避/穿透/急速/吸血/回能仍由同一核心执行。

“完整执行（须全部已迁移）”模式会阻止包含未迁移功能的测试。它不会假装完整执行73个动作。

独立测试不发奖励、不收集伙伴、不解锁正式商店、不推进正式楼层。奖励字段可以编辑和导出，本次测试不结算它们。测试结果显示实际伤害、治疗、护盾吸收，并可导出测试记录。

正式试跑和测试使用不同存档格式及存储键。Play始终取当前草稿的配置快照；旧测试不跟随之后的草稿变化。测试中刷新会恢复同一快照并保持暂停，正式进度同时保留。普通存档导入会拒绝测试存档。
