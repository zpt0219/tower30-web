# 网页配置工作台

工作台与正式100层流程共用同一个TS核心。网页编辑配置后点击Play独立测试，测试不计入正式通关、不发奖励、不改变正式存档。

## 操作

1. 运行 `npm run dev -- --host 0.0.0.0`，打开终端地址，点击首页“编辑属性与关卡 ▶ Play”或侧栏“工作台”。
2. 在“角色 · 43”选择人类或怪兽，修改“基础”和“每级成长”。右侧最终属性由同一核心计算，包含测试等级及已选初始装备。
3. 在“关卡 · 100”选择任一关，调整敌组与奖励；选中的关卡就是Play目标，不要求先通关。在“测试设置”调整阵容、等级、阶数、起始生命/能量和固定种子。
4. 在“技能”页编辑前后摇、弹道、倍率/固定值、可打断性及射程/范围/持续时间覆盖；清空覆盖框即恢复原规则。“效果与被动”编辑共用效果参数。
5. 在“战斗策略”编辑治疗阈值、打断条件、大招优先级和补人顺序；勾选自动执行后Play会按策略提交命令。
6. 点击“▶ Play 第N关”进入真实实时战斗。可暂停、倍速、单步1/60秒、手动大招、补人；“返回编辑”回到原面板，“重新Play”用本次冻结配置重开。

草稿自动保存到浏览器（IndexedDB），也可点击“保存草稿”。“导出工程 (ZIP)”包含 `trial-draft.json`、`tower30-editor-project.json`、怪兽图鉴清单与贴图；“导入”支持ZIP与工程JSON。无效输入会标出并禁用Play；导入先完整校验，失败不替换现有草稿。

静态网页不会覆盖磁盘上的 `data/tower/trial.json`。要把导出的工程设为仓库默认基线，运行 `npm run apply:baseline -- <ZIP或JSON路径>`。

内置基线更新后，浏览器中基于旧基线的草稿会自动备份到 `draftBackup`，工作台切换为最新基线并提示“基线已更新至100层（旧草稿已备份）”。

## 可编辑内容

| 模块 | 字段 |
| --- | --- |
| 43名角色 | 生命、攻击、防御、法术、魔抗、暴击、穿透、急速、闪避、吸血、韧性、充能；基础和每级成长分别编辑 |
| 行动与空间 | 定位、普攻类型、弹道、攻击间隔、技能冷却、前摇比例、移动速度、射程、碰撞半径 |
| 技能 | 普通技能/大招/被动选择，三级倍率与固定值，前后摇、弹速、范围、持续时间、持续伤害与护盾倍率 |
| 100个关卡 | 名称、主题、提示、背景、金币、装备奖励 |
| 每个敌组 | 增删编组、物种、数量、等级、阶数、生命/攻击与法术/防御倍率、战斗经验、魂魄、经验药水奖励；可清除专用技能覆盖 |
| 测试设置 | 任意关卡、1—10名我方角色、等级、怪兽阶数、生命比例、起始能量、种子、初始武器开关、技能测试模式 |

Boss固定为每5关一个（F5、F10……F100）；每关最多16名敌人，5首发，其余按补人票入场，每方最多10名存活在场。碰撞半径过大无法部署时，核心拒绝开战并还原战前状态。

百分比按0—100填写；叠加后保留属性硬上限：暴击75%、急速100%、闪避40%、吸血60%、韧性60%、充能效率100%。

## Play与批量对比

- “数值与已实现技能”模式会停用未迁移的技能/被动并明确列出；“完整执行”模式遇到未迁移功能直接阻止测试。
- Play使用当前草稿的配置快照；之后修改草稿不影响已开始的测试。测试中刷新会恢复同一快照并保持暂停。
- 批量对比：保存A → 修改草稿B → 选关（当前关卡 / 全部Boss关卡 / 全部关卡 / 手动勾选）→ 每关运行1—100个相同种子的配对。可取消、导出报告和单场记录、查看战果或用该种子手动/策略Play。只统计独立战斗，不模拟购买、培养或住宿。
- 逻辑固定60Hz。测试记录格式为 `tower30-ts-workbench-v7`，批测报告为 schemaVersion 4 / `tower30-policy-v3`；旧格式不再读取。

## 制作新怪兽

点击“＋ 新增怪兽”，填写名字、上传PNG、选择属性与技能模板，预览后确认创建。支持单张图和3列×4行行走图；图片随草稿、战中恢复和工程ZIP保留。详见[新怪兽制作说明](MONSTER-CREATION.md)。

## 相关代码

- `src/core/playtest.ts`：测试设置校验、未迁移功能报告。
- `src/core/engine.ts`：正式与测试共用的战斗、命令、tick、冻结配置与重放。
- `src/core/projections.ts`：最终属性及敌群倍率的唯一计算。
- `src/core/simulation.ts`：批量配对模拟、统计与单场记录。
- `src/editor/`：草稿模型、校验、各编辑面板、导入导出及浏览器保存。
- `src/storage/save.ts`：IndexedDB中的正式存档与工作台存储。
