# v0.4 · 正式前20层

v0.3/M2已提交为 `2939a31`，作为前10层可回退版本。v0.4继续推进M3，正式流程现开放第1—20层；第21—30层仍锁定，完整M3尚未完成。

## 规则与工作台

在原24个动作上新增15个：`drain / silence / spirit_armor / spirit_veil / leech / doublecut / mossheal / rooted_guard / curse / ice_shard / ice_domain / eye_ray / hard_shell / armor_front / boss_carapace`。共39个动作已迁移，工作台73个动作ID保持不变，未迁移项仍明确阻止或停用。

新增沉默、弱化、物理/法术防护、自身扎根、双段独立命中、同目标普攻连击，以及20层虫王的自疗和范围震击。相关三阶被动包括蚀能强化、法术/物理减伤、夜翼吸血、连击、苔衣自疗、弱化延长和受控追加。阶段0/1/2装备全部可用。

工作台和大招按钮显示中文技能名并保留稳定ID；新技能使用已有的时间轴、倍率、射程、范围和持续时间参数。Canvas和伙伴状态显示沉默、扎根、弱化、物理/法术防护。射程、倍率和时长由同一TS核心执行，界面没有第二套伤害计算。

- 沉默可取消自动技能和可打断大招；不可打断大招保留，普攻仍可行动。
- 防护仅减对应物理/法术类型，多个减伤取较强者并受原上限约束。
- 弱化在投射物发射时冻结；命中前弱化到期不会改变已发射的伤害。吸血按实际扣血统一计算并受60%上限约束。
- 扎根限制移动，自疗和行动仍执行；控制时长按韧性缩短。
- 多段动作逐段判闪避/暴击，并保留源端“任一段闪避时恢复该动作状态记忆”的护盾语义。正常资源对照与单独闪避用例均保留，未擅自修改原配表或规则。
